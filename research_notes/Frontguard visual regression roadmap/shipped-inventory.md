## What do README, CHANGELOG, and docs say the three packages do, and where do baselines live?

### Takeaway
`@frontguard/cli` is the local/CI visual-regression CLI with git orphan-branch baselines named `frontguard-baselines`. `@frontguard/playwright` is an in-test `visualTest()` helper whose PNGs live in `__visual_baselines__/`. `@frontguard/mcp` is a stdio MCP server that can read a local `report.json` with no cloud key. Pixel comparison is the pass/fail signal; model output is advisory. Those two baseline stores are different products, not two names for one store.

### Cited Findings

Model classification is advisory and unmeasured. ## Which listed capabilities already exist in code or docs?

### Takeaway
Pixelmatch pass/fail, Storybook `/index.json` discovery, CSS and pixel ignore masks, axe-core (optional peer), `freezeTime` / `seedRandom` / `blockUrls` / `waitForStability`, MCP local `report.json` cluster reads, and experimental judge mode are implemented in this tree. Firefox and WebKit capture are implemented but not the default. SSIM (including chroma-SSIM and CW-SSIM) exists; **odiff does not**. Changed-file report scoping exists as a smart filter. OpenTelemetry exists only as an undeployed cloud-api OTLP/HTTP exporter plus unused `@opentelemetry/*` version overrides — not as CLI instrumentation. PNG baseline-history pruning and test-coverage thresholds are documented as not done.
