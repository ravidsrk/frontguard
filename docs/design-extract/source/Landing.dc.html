// HOW FRONTGUARD THINKS

Not just "pixels differ." Detect, understand, fix.

01 / DETECT

Find what changed

Pixel comparison across configured viewports and browsers, with masks, thresholds, and optional multi-render consensus.

02 / UNDERSTAND

Explain why it broke

When configured, model-assisted analysis classifies changed screenshots and returns an explanation for human review.

03 / FIX

Experimental verification

CSS suggestions and sandbox verification are separate opt-ins. Unverified suggestions remain labeled as such.

// RUN IT YOUR WAY

One command, or three lines.

Run it standalone against any URL, or drop visual assertions straight into the Playwright suite you already have. No proprietary snapshot format, no test files to port.

Standalone CLI @frontguard/cli 
$ npx -p @frontguard/cli frontguard run

  ✓ 11 passed   ✘ 1 regression
  AI: "submit button lost its background"

Point it at any URL. It auto-discovers routes, renders, diffs, and posts the verdict — zero test files to write.

Playwright-native @frontguard/playwright 
import { test, expect } from '@playwright/test';
import { visualTest } from '@frontguard/playwright';

test('home page', async ({ page }) => {
  await page.goto('/');
  const result = await visualTest(page, 'home-page');
  expect(result.passed).toBe(true);
});

Three lines in a test you already wrote. Reuses the page Playwright just rendered — no second browser launch.

// CONFIGURATION

One file. Sensible defaults.

Auto-discover routes by crawling, or list them explicitly. Set per-route thresholds — strict on /checkout, relaxed on /blog.

frontguard init auto-detects Next.js, Remix, SvelteKit, Nuxt or Astro and writes this for you.

frontguard.config.ts 
export default {
  baseUrl: 'http://localhost:3000',

  // auto-discover routes (zero config)
  discover: {
    startUrl: '/',
    maxDepth: 3,
    exclude: ['/admin/*', '/api/*'],
  },

  viewports: [375, 768, 1440],
  browsers: ['chromium'],
  threshold: 0.1,

  // AI analysis (optional, BYOK)
  ai: { provider: 'openai', model: 'gpt-4o' },
};

// NO MAGIC, JUST HONEST

We'll tell you what it isn't.

Skeptical engineers built this for skeptical engineers. No silver bullets — here's exactly where the edges are.

YOU BRING THE KEY

AI is optional and uses your selected OpenAI or Anthropic account. Screenshot evidence goes directly to that provider, not through a Frontguard proxy.

YOU STAY IN THE LOOP

High-confidence intentional classifications automatically downgrade regressions to warnings. With fix verification enabled, a verified fix is automatically recorded as an accepted local fix-pattern signal. Neither behavior updates baselines; review model output and patches.

NUMBERS, NOT CLAIMS

It's young. The published harness discloses repository boot failures and that AI accuracy was not measured. Trust starts with visible limits.
