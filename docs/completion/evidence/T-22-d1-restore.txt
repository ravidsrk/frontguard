# T-22 — scratch D1 Time Travel restore — 2026-10-19

No production D1 exists. `wrangler d1 list` was `[]` before this drill and `[]`
after the scratch database was deleted. `cloud-api` was not deployed.

Retention. Cloudflare's Time Travel doc (updated 2026-04-21) says a database
can be restored up to 30 days on the Workers Paid plan and 7 days on the
Workers Free plan. Time Travel is on for databases whose `version` is
`production`; it is not a switch. This account's Workers Paid subscription is
Expired, so the window that applies is 7 days. The scratch database was created
during the drill (`version: production`), so this transcript proves a restore,
not a 7-day-old bookmark.

Wrangler 4.151.1. Auth was the global API key plus email, with
`CLOUDFLARE_ACCOUNT_ID` set and `CLOUDFLARE_API_TOKEN` unset. Commands ran with
`--cwd /tmp` so they could not edit a repo wrangler config.

## Steps

    wrangler d1 create frontguard-restore-drill --location enam
    # created database_id 278ab0a2-0a20-4921-b5da-48601d343b27
    # version production, region ENAM

Insert via the D1 query API:

    CREATE TABLE IF NOT EXISTS drill (id INTEGER PRIMARY KEY, note TEXT);
    INSERT INTO drill (id, note) VALUES (1, 'before-delete');

`SELECT id, note FROM drill` returned one row: `1 | before-delete`.

Bookmark for that moment came from
`GET /accounts/{account}/d1/database/{id}/time_travel/bookmark`
and from `wrangler d1 time-travel info frontguard-restore-drill`.
Wrangler's `d1 execute --json` output did not include a bookmark.

    DELETE FROM drill WHERE id = 1;

`SELECT` then returned `results: []`.

    wrangler d1 time-travel restore frontguard-restore-drill --bookmark <bookmark captured above>

Restore response:

    message: Resetting Durable Object to restore database to bookmark: 00000000-00000008-00005109-03b7c25473bb17fc62d4ca07d9645df8
    previous_bookmark: 00000000-ffffffff-00005109-cab0525e5e4af9b5f2382256a0f0783c

`wrangler d1 execute frontguard-restore-drill --remote --command "SELECT id, note FROM drill;"`
returned the row again: `1 | before-delete`.

## Cleanup

    wrangler d1 delete frontguard-restore-drill --skip-confirmation
    # Deleted 'frontguard-restore-drill' successfully.
    wrangler d1 list
    # []
